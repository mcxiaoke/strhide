# CHANGES 2026-11-25

## 2026-11-25 19:02:26 fix(gui): fix batch cancellation, cross-tab run lock, capacity/extract state bugs, and log modal/i18n issues

1. **任务取消传播、全局并发锁与状态一致性（`gui/src/store/{taskStore,settingsStore}.ts`、`gui/src/hooks/{useSequentialJob,useFileQueue,useStegoAlgorithms}.ts`、`gui/src/main.tsx`）**
   - `taskStore` 新增 `cancelRequested` 标志，`useSequentialJob` 在触发取消或收到 `cancelled` 错误后中止后续队列项，并检查全局 `isRunning` 防止多页签并发冲突。
   - `StegoEmbedView`、`HideStructureView`、`ExtractView`、`ScanView` 接入全局忙碌态锁定控件与拖拽上传；按需清理空队列或已移除项的容量/结果/密码提示状态。
   - 启动时通过 `syncInitialLang` 同步前端语言至后端与 `<html lang>`；`useStegoAlgorithms` 请求失败时重置 `pending` 且不写入空数组缓存，允许后续重试。
   - `useFileQueue` 记录 `modifiedMs` 并过滤 `exists === false || is_file === false` 的无效路径；`PayloadEditor` 过滤异步选择文件的过期元数据回调。

2. **隐写、提取、扫描与路径/错误处理修复（`gui/src/views/*`、`gui/src/lib/{format,errorHandler,i18n}.ts`、`gui/src/types/strhide.ts`、`gui/tests/unit/errorHandler.spec.ts`）**
   - `StegoEmbedView` 改用结构化容量缓存键（含路径、大小、修改时间、密码、安全等级、算法），计入文件载荷名头开销，传递 `updateProgress`，区分支架错误与跳过态，并在空文件载荷时允许执行。
   - `StegoEmbedView` 与 `HideStructureView` 展示结构化 `warnings`；`HideStructureView` 在清空密码时同步复位 `stealth`。
   - `ExtractView` 支持空文本预览（`text_preview !== undefined && text_preview !== null`）、展示密码提示（`PasswordRow.hint`）及处理剪贴板写入异常；`ScanView` 修正 `encrypted` 不再将普通隐写误判为加密。
   - `dirName` 保留 `/` 与 `C:\` 根目录；`parseStrHideError` 从后端 `already_exists` 详情中剥离单引号路径；修正 `i18n` `stego.fileHint` 移除未支持的 WebP 并补充实际支持格式。

3. **日志面板与类型修复（`gui/src/api/commands.ts`、`gui/src/lib/frontendLogger.ts`、`gui/src/store/logStore.ts`、`gui/src/components/common/LogModal.tsx`）**
   - `getRecentLogs` 与 `listen("app:log")` 使用 `RustLogEntryDto`；`wrapConsole` 经 `queueMicrotask` 异步入队避免 React 渲染期同步触发 Store 更新；`addEntries` 补全批量错误未读计数。
   - 新增 `safeJsonStringify` 防止循环引用抛出异常；修复 `LogModal` `null` 数据打印、2000 条满额淘汰后的自动滚屏、`py-0.5` 样式与最大化按钮本地化文案。

## 2026-11-25 18:56:08 fix(gui-tauri): fix extract cache invalidation, dir extract overwrite guard, audio tuning, and batch inspect limit localization

1. **智能提取缓存边界与失效修复（`gui/src-tauri/src/state.rs`、`gui/src-tauri/src/commands/{stego,structure}.rs`）**
   - `CachedExtract` 增加 `file_size` 校验并限定单条缓存上限 `EXTRACT_CACHE_MAX_BYTES`（4 MiB），避免在 Windows mtime 精度内文件改写被误命中及大文件载荷常驻内存。
   - 新增 `GuiState::invalidate_extract_cache`，在 `embed_stego_file_impl`、`write_structure_file_impl`、`restore_structure_file_impl` 及 `smart_extract_impl` 写出目标文件成功后立即清理关联路径缓存。

2. **提取输出目录与音频/批量/DTO 细节修复（`gui/src-tauri/src/commands/{stego,batch,diag}.rs`、`gui/src-tauri/src/logger.rs`）**
   - `smart_extract_impl` 在目标为已存在目录且 `overwrite=false` 时放行入口校验，仅在确定写出具体目标文件 `target_file` 时执行 `check_overwrite`。
   - `resolve_tuning` 将音频算法 `"wav_pcm"` / `"flac_residual"` 映射为 `StegoTuning::audio(AudioParams::default())`。
   - `batch.rs` `"inspect"` 分支对齐 `inspect_carrier_with_task`，通过 `strat.render_limit(ctx)` 本地化策略容量上限文本。
   - 为 `LogEntryDto.data` 与 `FileMetadataDto.modified_ms` 添加 `#[serde(skip_serializing_if = "Option::is_none")]`。
