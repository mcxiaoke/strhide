## 1. 核心结论先行

1. **“防指纹”与“抗检测”是两个不同维度的概念，不可混淆**：
   * **防指纹（Anti-Fingerprinting / Dialect Separation）**：防止分析者/审查者确认“这是 strhide 产物”并**定向提取**秘密。决定因素是**密钥系统、KDF 域分隔符、头部槽位伪随机洗牌种子、STC 校验矩阵种子及嵌入通道**。这些参数由调用方私有化定制后，**完全不损害图像质量与隐写抗检性**，却能使官方开源工具或公开提取器直接报 `NoHiddenData`。
   * **抗检测（Anti-Steganalysis / Undetectability）**：防止检测者在未知密钥的情况下，通过统计异常、残差噪声分布或深度神经网络发现“该图疑似隐写”。决定因素是**载荷率（容量利用比例）、编码改动率（STC 网格码）与失真代价函数（HILL / UERD）**。
2. **算法内部参数绝非“越多越可配越好”**：
   * HILL 高通滤波核、两次低通平滑窗口（3×3, 15×15）、八值类掩码（`& 0xF8`）、UERD 邻域阻尼权重（0.25）等，是李斌（Bin Li）与 Fridrich 等学者在全量自然图像集上对抗高阶空间残差特征训练出的**数学最优解**。
   * 随意暴露给调用者修改，不仅**毫无去指纹作用**（统计检测器不看这些配置，只看像素二阶导数分布），反而极易破坏失真代价分布，导致高熵载荷落入平坦区，盲检分数激增；甚至破坏提取端 LSB 不敏感性不变形，导致解不出载荷。
3. **黑盒对抗视角下，压低检测率的决定性因素排序**：
   $$\text{有效载荷率（容量保守系数）} \gg \text{STC 最小改动率（u=3）} > \text{平滑区硬排除比例} > \text{三通道打散} > \text{类内三进制 }\pm 1\text{ 移动}$$
   微调滤波器的浮点数在上述因素面前属于高阶无穷小，不应作为使用者调优手段。

## 3. 主流工具的黑盒检测层级与攻击面分析

从黑盒检测者的探测视角，一个载体文件会经历以下四层递进式探测：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 第 1 层：结构、元数据与视觉切片层 (AperiSolve, stegoVeritas)             │
│   • 探测手段：EOF 尾部追加、非标 Chunk、Bit Plane 0 噪点、局部信息熵突变 │
├────────────────────────────────────────────────────────────────────────┤
│ 第 2 层：统计学二阶差分层 (Stegcore, stegolab, zsteg)                   │
│   • 探测手段：卡方 PoVs 对称性拉平、相邻像素样本对状态转移 (SPA / RS / WS) │
├────────────────────────────────────────────────────────────────────────┤
│ 第 3 层：频域前向校准层 (stegdetect, calibration.py)                    │
│   • 探测手段：像素解压错位 4 像素重压缩，对比原图与基准图的 DCT 交流系数分布  │
├────────────────────────────────────────────────────────────────────────┤
│ 第 4 层：高维残差特征与端到端 CNN (Aletheia: SRM, SRNet, XuNet)          │
│   • 探测手段：高通滤波剥离图像语义，3.4 万维共生矩阵 / 深度卷积特征分类   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 第 1 层：结构、元数据与视觉切片层

* **检测机制**：
  * **结构完整性**：检查 PNG 的 `IEND` 之后或 JPEG 的 `EOI` 之后是否存在未经注册的垃圾字节（Overlay 注入直接暴毙）。
  * **私有元数据**：`pngcheck` / `exiftool` 扫描非标 Chunk（如 strhide 的 `prIv`）或反常 APPn 段。
  * **位平面切片（Visual Attack）**：提取第 0 位平面（最低有效位 LSB），生成单色二值图。自然图像在天空、大理石、纯色边缘处的 LSB 仍具备一定的纹理连续性；若是盲目随机嵌入，平滑区域会呈现出规整的“高熵雪花白斑”，肉眼一目了然。
* **strhide 现状**：
  * 内容域（`embed`）完全抛弃了结构注入，直接修改像素/频域系数，结构层检测为 0 风险；
  * 但若平滑区未剔除彻底，容易在位平面切片上露出马脚。

### 3.2 第 2 层：统计学二阶差分层（$\chi^2$, SPA, RS）

* **检测机制**：
  * **卡方检验（Chi-Square Test）**：针对经典 LSB 替换（$2k \leftrightarrow 2k+1$）。自然图像中灰度为 $2k$ 与 $2k+1$ 的像素数量天然存在统计差异；简单 LSB 替换会把两者频数强行拉平（对折）。卡方检验计算观测频数与期望频数的方差，很容易检出大载荷 LSB 替换。
  * **样本对分析（Sample Pair Analysis - SPA）**：分析相邻像素 $(u, v)$ 在翻转操作下的状态转移。根据有限状态机方程，可以直接反解出全图的“嵌入率估计值 $p$”。
* **strhide 现状**：
  * 已引入**三进制类内 $\pm 1$ 移动（Ternary Matching）**：像素变化不再局限于偶奇对折，而是向局部均值方向微调，统计质量跨越成对边界，卡方检出率直接失效；
  * **STC 分组网格（$u=3$）** 将每 bit 改动数从 0.50 压到 0.22，SPA 检出的信噪比极低。

### 3.3 第 3 层：频域前向校准层（JPEG Calibration）

* **检测机制**：
  * 隐写前后的 DCT 系数宏观直方图差异不大，但由于嵌入只修改了 AC 频域系数，破坏了量化表与空间平滑性的天然约束。
  * 检测器将 JPEG 还原为像素，向内裁剪 4 像素（打破原 $8\times 8$ 网格对齐），重新按原量化表压缩得到“去隐写估计基准图”，比对真实图片与估计图在成对交流系数（如绝对值为 2 与 3、4 与 5）的分布比率。
* **strhide 现状**：
  * 纯替换修改 AC 系数会被成对失衡校准捕获；本项目今日已实现 `dct:calibration` 自检。UERD 通过高能量 DCT 块阻尼，在低载荷下校准比率处于干净基线内，但满载下仍有可检出特征。

### 3.4 第 4 层：高维残差特征与端到端 CNN（SRM, SRNet）

* **检测机制**：
  * 现代隐写分析的核心突破。**SRM（Spatial Rich Models）** 采用 30 个不同的线性和非线性高通滤波残差，在 4 个方向上提取二阶、三阶与四阶共生概率分布，形成 34,671 维特征向量。
  * **SRNet（Steganalysis Residual Network）**：端到端深度卷积网络。前几层直接使用固定高通核剥离图像语义主体，后续层自适应学习隐写噪声模式。
* **学术界公认规律（真实大图评测）**：
  * **高载荷（$0.4 \sim 0.5\text{ bpp}$）**：无论 HILL 还是 S-UNIWARD，SRNet / SRM 检出准确率高达 **85% ~ 95%**；
  * **低载荷（$0.1 \sim 0.15\text{ bpp}$）**：检出准确率剧降至 **58% ~ 65%**（$P_E \approx 35\% \sim 42\%$，接近随机猜测的 50% 基线）。

## 4. 关键参数对降低检测率的真实功效评估

对照上述检测原理，我们对所有候选参数的作用深度进行严谨分类：

### 4.1 核心防护参数（对降低检测率起决定性作用）

#### ① 实际载荷率与安全容量预算（`recommended_max_bytes`）
* **定位**：**头号防御屏障**。
* **原理**：没有任何隐写算法能在满载时抵挡 SRNet 和 SRM 的特征提取。降低被检率最有效的手段是**主动限制嵌入载荷占可用槽位的比例**。
* **实证**：本项目今日实施的 `recommended_max_bytes` 统一将安全工作点锚定在 $r = \frac{\text{available\_slots}}{\text{needed\_bits}} \ge 4.5$（对应 STC $u=3$ 最优区间）。在此区间内盲检风险跳变率从满载的 87.5% 暴跌至 **$< 7.5\%$**。

#### ② 编码层最小改动率（`StegoCodec::Auto` / `STC u=3`）
* **定位**：**结构失真压制器**。
* **原理**：同等载荷下，改动的像素越少、加权失真 $\sum \rho$ 越小，留在图像二阶统计量中的痕迹就越浅。
* **实证**：STC $u=3$ 将改动率压低到 **0.22~0.23 flips/bit**（比普通 LSB 减少近 60% 改动）。即使检测器做相邻差分，残差能量也远低于自然图像噪声方差。

#### ③ 平滑区域硬排除比例（`exclusion_percentile` / `block_exclusion_percentile`）
* **定位**：**视觉与分块熵防御线**。
* **原理**：AperiSolve 位平面目测与分块信息熵检测最容易在低方差平坦区抓现行。彻底将最平坦的 20%~30% 像素/频块从候选集中剥离，确保所有改动 100% 混入复杂纹理。

#### ④ 嵌入通道伪随机打散（`channel_spread`，待扩展）
* **定位**：**破除单通道先验**。
* **原理**：目前 PNG 固定只修改绿色通道（Green）。多通道分析工具比对 R、G、B 残差时，绿色通道会呈现异常方差峰值。若能将正文槽位依据密钥伪随机均摊到 R、G、B，单通道改动率立即降为 $\frac{1}{3}$，信噪比腰斩。

### 4.2 内部硬约束参数（调优固化，严禁暴露）

以下参数必须由库内部统一管理，**绝不能**向普通调用方开放：

* **高通滤波核 `high_pass_kernel` 与平滑窗口 `p1_window, p2_window`**：
  * 论文最优配置（KB 核 + 3×3/15×15 级联低通）。使用者自行调参几乎必然劣化高频定位，导致平滑区被误选。
* **八值类掩码 `val & 0xF8` 与值域范围 `[8, 247]`**：
  * 保证提取端重算 HILL 代价图逐位一致（LSB 不敏感性）的数学基石。一旦改动，提取端排序错位，导致 `NoHiddenData`。
* **UERD 最小绝对系数值 `min_abs_coeff = 2`**：
  * 保护 JPEG AC 游程编码的数学硬红线，绝对不可小于 2。
* **UERD 邻域权重 `neighbor_weight = 0.25`**：
  * 8 邻域能量阻尼的最优经验值。

## 5. 备忘结论

1. 提高隐写隐蔽性的技术路径非常明确：**管住载荷率（容量保守控制） + 强化 STC 网格码（降改动率） + 坚持纹理自适应（HILL/UERD 内部最优滤波）**。
2. 消除开源代码公开指纹的路径同样明确：**私有隐写密钥（`default_secret`） + 私有 KDF 派生域（`stego_domain`） + 通道打散**。
3. 后续对外公开的 API 应当顺应这一规律进行参数收敛，屏蔽低层数学细节，只留高层安全策略。详细工程落地见配套实施文档。
