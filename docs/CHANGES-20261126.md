# CHANGES 2026-11-26

## 2026-11-26 12:47:43 refactor(cli): replace I/O, format, password, and limit General errors with typed variants

1. **带上下文的 I/O 与写出错误结构化（`rust/src/cli/{helpers,cmd_structure,cmd_diag}.rs`）**
   - 在 `cli::helpers` 提取共享辅助函数 `io_with_context(kind, msg)`，为终端读取密码/确认密码、`--password-file`、`--key-file` 与 `scan` 全缺失输入保留路径/操作上下文及精确 `std::io::ErrorKind`。

2. **载体格式、密码缺失与载荷上限变体对齐及回归测试（`rust/src/cli/{helpers,cmd_stego}.rs`、`rust/tests/test_cli/cli_unification.rs`）**

   - 为 `cli::helpers` 补充单元测试 `helpers_return_typed_errors_instead_of_general`，并在 `cli_unification` 新增端到端测试 `cli_error_categories_preserve_semantic_prefixes` 覆盖中英文 `[ERROR]` 分类前缀与退出码。

## 2026-11-26 12:42:34 refactor(cli): replace argument validation General errors with InvalidArgument and preserve single-carrier capacity errors

1. **参数校验错误分类结构化（`rust/src/cli/{cmd_stego,cmd_structure,cmd_diag,helpers}.rs`）**
   - 将 19 处参数缺失/标志冲突/非法格式校验由 `StrHideError::General` 替换为 `StrHideError::InvalidArgument`，保持 `[ERROR] {detail}` 输出格式不变的同时提供准确的 `ErrorKind::InvalidArgument` 分类。

2. **单载体容量探测错误透传（`rust/src/cli/cmd_stego.rs`）**
   - `probe_capacity_many` 在单载体失败场景下改为直接返回底层 `last_error` 原错误，不再经 `General(format!(...))` 洗掉 `UnsupportedFormat`、`Io`、`Cancelled` 等原始错误分类；多载体汇总及 `--json` 序列化失败等场景仍保留 `General`。
