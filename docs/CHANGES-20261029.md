### 2026-10-29 08:38:21 - 添加 CLI 与 GUI 一键自动化发布打包脚本 scripts/release.py

- **改动概述**：
  1. 新增发布脚本 [`scripts/release.py`](file:///c:/Home/Projects/strhide/scripts/release.py)：
     - 参考 `CarroDesk`、`jigsawpuzzle` 等项目规范设计，提供自动化打包与版本分发能力；
     - 自动解析 `rust/Cargo.toml` 与 `gui/src-tauri/tauri.conf.json` 的统一版本号（支持命令行传入自定义版本号，如 `0.7.4` 或 `v0.7.4`）；
     - 支持跨平台操作系统与架构识别（如 `windows-x64`、`linux-x64`、`macos-arm64`）；
     - CLI 打包：编译 `cargo build --release --features cli`，产物及文档打包为 `release/v<version>/strhide-cli-v<version>-<platform>.zip`；
     - GUI 打包：编译 `pnpm tauri build --no-bundle`，将单文件便携式程序及文档打包为 `release/v<version>/strhide-gui-v<version>-<platform>-portable.zip`（仅保留单一核心主程序 `strhide-gui.exe`，避免包内重复冗余）；
     - 自动检测并归档 Tauri 产出的 `.msi` / `.exe` 等安装包（若生成）；
     - 自动生成符合标准的 `SHA256SUMS.txt` 校验清单。
  2. 实用命令行选项支持：
     - `--cli-only` / `--gui-only`：单目标打包；
     - `--skip-build`：跳过编译快速重打包已有产物；
     - `--clean`：清理旧的 release 目标文件；
     - `--dry-run`：试运行步骤预览；
     - `--open`：打包完成后在资源管理器中自动打开目标目录。
- **验证**：
  1. 运行 `python scripts/release.py --dry-run` 预览流程通过；
  2. 运行 `python scripts/release.py` 全量打包成功：
     - `release/v0.7.4/strhide-cli-v0.7.4-windows-x64.zip`（1.41 MB）；
     - `release/v0.7.4/strhide-gui-v0.7.4-windows-x64-portable.zip`（4.21 MB）；
     - `release/v0.7.4/SHA256SUMS.txt`（校验清单生成完整）；
  3. 解压校验 zip 包文件结构，CLI 与 GUI 便携包内容完备无误。
