## 2026-11-09 12:02:14 — CLI 体验增强：载体/载荷人性化报错与国际化、多载体批量预检、-v/vv/vvv 诊断日志分级修复与 CLI 文档同步

- **载荷与载体人性化报错与多语言支持**：
  - **载荷文件不存在友好提示**：`-d / --data` 载荷文件缺失时不再暴露裸 `io::Error`，而是明确输出具体路径，并友好提示“若需直接隐藏文本内容，请使用 -t/--text 代替 -d/--data”，解决命令使用歧义；
  - **目录类型防护**：增加载荷与载体目录检查，误传入目录时给出明确压缩归档或指定有效文件的中文/英文提示；
  - **多载体批量预检一次性汇总**：统一实现 `validate_carriers_exist`，覆盖四大域全部 6 个操作动词（`write`, `read`, `restore`, `embed`, `extract`, `capacity`）；当传入多个载体且多个文件不存在时，一次性输出所有缺失文件清单并双语本地化，避免逐个尝试。
- **日志级别映射与诊断输出修复 (-v / -vv / -vvv)**：
  - **规范化等级映射**：将 `level_for` 调整为标准四档：0: Warn, 1: Info (`-v`), 2: Debug (`-vv`), 3+: Trace (`-vvv`)；
  - **重入与最大等级保护**：修复进程内多次运行或测试时未能更新 `log::set_max_level` 的问题；
  - **关键路径打点**：在 logger 激活时打印 `Diagnostic logging active: level={level}`，并在各子命令分发入口输出载体数量与执行模式等关键诊断信息至 stderr，确保 `-v` 实时可见生效。
- **文档更新**：
  - 更新 `docs/CLI_GUIDE.md`：补充 `-v` 分级行为说明、载荷与多载体预检校验规则、`--no-preserve-time` 时间戳控制等。
- **测试与验证**：
  - 在 `rust/tests/test_cli/i18n.rs` 中新增 3 项针对性集成测试（`-d` 友好提示、多载体缺失汇总、`-v` 诊断日志），140 项 CLI 测试全绿通过。

## 2026-11-09 10:35:22 — CLI 优化：彻底统一四大动词 -e/--prompt-password 参数并消除 encrypt 歧义

- **extract 执行流与 embed 严格对称**：

## 2026-11-09 10:02:09 — CI 修复：解决 Desktop GUI Release 工作流 pnpm workspace 缺失 packages 报错

- **问题背景**：推送 tag 触发 release 时，`.github/workflows/gui-release.yml` 的 `build-tauri` 多平台任务在 `pnpm install` 阶段报错 `ERROR packages field missing or empty` 并退出。

- **变更详情**：
  - 在 `gui/pnpm-workspace.yaml` 中补充 `packages: - '.'`，显式声明根包范围，确保各版本 pnpm 均能正确识别。
  - 将 `.github/workflows/gui-release.yml` 中的 `pnpm/action-setup@v4` 版本配置由 `version: 9` 升级为 `version: 12`，与本地开发环境（v12）对齐。
- **本地验证**：
  - `gui` 目录下 `pnpm build`（TypeScript 类型检查 + Vite 打包）、`cargo clippy` 检查通过。
  - Playwright 单元测试 `pnpm test:unit`（24 passed）、跨层交叉测试 `pnpm test:cross`（7 passed）、全量 E2E 测试 `pnpm test:e2e`（25 passed，含 WCAG 对比度审查）全部通过。
