# 桌面端使用指南 (StrHide Studio)

> 适用 `StrHide Studio` 0.9.x（Tauri 2 + React）。命令行用法见 [CLI_GUIDE.md](CLI_GUIDE.md)，二者能力差异见 §7。

---

## 1. 先看术语：界面的"隐写"和"嵌入"指什么

桌面端刻意避开了"载荷/信封/系数"这类实现词，代价是**界面的两个词和 CLI 的两个命令是交叉映射的**。第一次用时先对齐这张表，否则会选错入口。

| 界面上的说法 | 实际含义 | 对应 CLI | 原文件能否还原 |
| :--- | :--- | :--- | :--- |
| **隐写**（页签 1） | 把内容写进图片/视频的**画面数据** | `sth embed`（内容域） | **不能**，画面已被修改 |
| **嵌入**（页签 2） | 把内容写进文件的**内部结构** | `sth write`（结构域） | **能**，位精确还原（用 CLI `restore`） |
| **提取**（页签 3） | 从文件里取回内容，两种方式都认 | `sth extract --auto` / `sth read` | — |
| **扫描**（页签 4） | 只读检测，不改文件 | `sth scan` + `sth inspect` | — |
| 内容 | 被隐藏的文字或文件 | payload | — |
| 文件 | 承载内容的文件 | carrier / host | — |
| 容量 | 这个文件最多能写入多少字节 | capacity | — |
| 隐蔽强度 | 隐写页的安全档位（最高/高/中） | `--safety paranoid/high/balanced` | — |
| 无痕模式 | 嵌入时不留下可识别的信封特征 | `--stealth`（必须设密码） | — |

一句话选择：**要"文件还能原样还原"就用「嵌入」，要"内容藏在画面里、经得起元数据清洗"就用「隐写」。**

## 2. 界面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ S StrHide │ 隐写  嵌入  提取  扫描 │            日志 主题 语言 │
├──────────────────────────────────────────────────────────────┤
│  文件队列（拖入或点击添加，可多选）                            │
│  密码 / 密码提示 / 保存到 / 高级选项                           │
│  [开始…]                                                      │
│  脚注：当前方式的能力与限制                                     │
└──────────────────────────────────────────────────────────────┘
```

- **顶部三枚按钮**：`日志` 打开日志与调试面板（有错误时红点提醒）、`主题` 切换浅色/深色（默认浅色，选择会记住）、`语言` 中英切换。
- **文件队列**：支持拖拽与多选；每项显示格式、容量、状态（待处理 / 处理中 / 完成 / 跳过 / 失败）与原因。格式不匹配当前页签的文件会在添加时直接标为"格式不支持"并给出建议页签（例如把 PDF 拖进「隐写」页会提示"不支持隐写，请用「嵌入」"）。
- **批量**：队列里所有受支持的文件会被依次处理，单个失败不影响其余，最后汇总"完成 n / 跳过或失败 m"。
- **可取消**：处理中可以取消，当前文件停下，已完成的结果保留。

## 3. 隐写（内容域）

把内容写进画面数据，写入后文件外观正常但**无法还原为原文件**。

1. 添加载体：PNG、JPG、WebP、MP4（HEVC）。容量在添加后即计算并显示，格式不支持的文件会在队列里直接标注。
2. 填写要隐藏的内容：`文字` 页签直接输入，`文件` 页签选一个文件。
3. 设置密码（可留空）。**留空意味着任何官方 strhide 都能读出**——见 [THREAT_MODEL.md](THREAT_MODEL.md) §4。
4. 选择**隐蔽强度**：
   - `最高（容量最小）` = `paranoid`，载荷率最低，最不容易被统计检测；
   - `高（推荐）` = `high`，默认；
   - `中（容量较大，更容易被检测）` = `balanced`。
5. 打开`高级选项` 可选算法：`自动（推荐）` 或具体模型（PNG：HILL / S-UNIWARD / MiPOD；JPEG：UERD / J-UNIWARD / J-MiPOD）。**队列里出现多种格式时只能选自动**，否则界面会把算法强制回 `auto`——因为同一个算法 id 在不同格式上不通用。
6. 勾选`超出容量上限时跳过该文件`（相当于 CLI 的 `--enforce-safety`）：超出所选档位上限的文件直接跳过，而不是硬写。
7. 选择`保存到`：默认与原文件同目录，输出名为 `<原名>-out.<扩展名>`；同名已存在时会提示更换目录。
8. 点`开始隐写`。

进度条会显示阶段（读取 / 分析 / 计算 / 写入 / 校验）。单个文件超出容量时，界面直接给出"最多可写入 X"。

> 写入后不要再用任何工具"另存"这个文件：有损重编码会永久毁掉内容，且失败与密码错误在界面里是同一句提示。

## 4. 嵌入（结构域）

把内容写进文件内部结构，文件可正常打开，并且**能被 CLI 位精确还原**（桌面端不提供还原，见 §7）。

1. 添加任意受支持文件（PNG、JPG、MP4/MOV/MKV、WAV、ZIP/JAR/DOCX/XLSX/PPTX、PDF、EXE/DLL，以及 WebP）。
2. 填写内容（文字或文件）。
3. 设置密码（可留空）。填了密码后可以设置**密码提示**（`例如：我的生日`），提取失败时会回显提示。
4. 需要更高隐蔽性时勾选`无痕模式`：它把信封魔数与头部字段改为口令派生值，无口令探测看到的是噪声。**无痕模式必须先设密码**，否则界面直接报错。
5. 选择`保存到`，点`开始嵌入`。

注意两点：

- 桌面端**不生成 `.bak` 备份**（后端以 `backup: false` 调用）。要保留原件请自己先复制，或用 CLI 的默认备份行为。
- 签名文件会被拒绝：PE 带 Authenticode、PDF 带 `ByteRange` 签名、签名 JAR 都会报"Rejection"，因为任何注入都会破坏签名。

## 5. 提取

自动识别两种写入方式，不需要事先知道文件是怎么写的。

1. 添加文件（隐写与嵌入的产物都行，也支持批量）。
2. 内容加密时填密码；未加密可留空。
3. 点`开始提取`。

结果分两类：

- **文字**：直接显示在结果区（等宽字体，可复制），并标注来源是"隐写内容"还是"嵌入内容"；
- **文件**：按内容里的原始文件名，保存到`保存到`指定的目录（未指定则与载体同目录）；同名文件自动加后缀，不覆盖已有文件。

如果文件里同时存在两种内容，界面会附带提示"（另有…）"，指出另一种内容来自哪个域。提取内部是两阶段（先探测再落盘），第二次会命中缓存，不会重复解码。

## 6. 扫描

只读检测，**不会修改任何文件**。

| 列 | 含义 |
| :--- | :--- |
| 文件 / 格式 | 路径与识别出的容器格式 |
| 写入方式 | `隐写` / `嵌入` / `不支持`（即该格式能承受哪一类写入） |
| 隐藏内容 | `含有隐藏内容` / `未发现` / `隐写 + 嵌入` |
| 是否加密 | 需要密码才能解开时为"是"，否则"—" |
| 内容大小 | 探测到的内容字节数 |
| 容量 | 该文件在当前方式下的可写入上限 |

扫描是无口令的黑盒判断，结论是启发式的：`未发现` 不等于"绝对没有"，只是没有命中结构特征或统计异常。

## 7. 与 CLI 的能力差异

| 能力 | 桌面端 | CLI |
| :--- | :--- | :--- |
| 隐写 / 嵌入 / 提取 / 扫描 | 支持 | 支持 |
| **位精确还原（restore）** | **不支持**（脚注会提示用 CLI `strhide restore`） | 支持 |
| 原地写入 | 不支持（总是写到目标目录） | `--in-place` |
| 自动生成 `.bak` | **不生成** | 默认生成，`--no-backup` 关闭 |
| 确定性种子 `--seed` | 不支持 | 支持 |
| `--dry-run` 演练 | 不支持 | 支持 |
| JSON 输出、`--fail-on` 门禁 | 不支持（界面已结构化） | 支持 |
| 算法微调参数（`--p1-window` 等） | 不支持 | 支持 |
| 私有方言 / 自定义 profile | 不支持（需编译期决定） | 需自建二进制，见 [PRIVATE_BUILD.md](PRIVATE_BUILD.md) |

批量、日志、进度、取消是桌面端的强项；需要可复现、可脚本化、可还原时用 CLI。

## 8. 日志与调试面板

顶部`日志`打开浮层，可切换来源（Rust 后端 / GUI 前端）、级别（全部 / …）、按关键词搜索、自动滚屏、清空、复制全部或复制筛选结果，并展开单条日志的原始 JSON。

用途是排障：失败时它会给出后端返回的错误码与上下文，比界面上的单句提示详细得多。**提交 issue 时请附上相关日志片段**，但先删掉真实路径、口令与内容——日志里可能包含这些。

## 9. 常见提示与处理

| 界面提示 | 原因 | 处理 |
| :--- | :--- | :--- |
| `密码不正确，或该内容需要密码才能提取` | 密码错、算法/方言不匹配，或根本没有内容——三者不可区分 | 确认密码与来源；用「扫描」先看是否有内容及是否加密 |
| `目标文件已存在` | 输出目录有同名文件 | 换目录（桌面端不覆盖） |
| `目标文件被占用` | 文件被播放器/看图工具打开 | 关闭占用程序后重试 |
| `内容超出所选隐蔽强度的容量上限` | 载荷大于档位上限 | 降载荷、升档位（降到 `中`）、或换更大的载体 |
| `格式不支持` + 建议页签 | 把文件加到了错误的页签 | 按提示切到「嵌入」或「隐写」 |
| `还原校验未通过` | 载体已被二次处理 | 见 [THREAT_MODEL.md](THREAT_MODEL.md) §4，原宿主已不可恢复 |
| 启动即被杀软/SmartScreen 拦 | 产物未签名 | 见 [INSTALL.md](../INSTALL.md) §1 |

更多问题见 [FAQ.md](FAQ.md)。
