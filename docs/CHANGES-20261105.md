## 2026-11-05 15:22:15 — F-28 核验：PNG 嵌入路径无重复解码，仅修正过时注释

- 结论：V4 重构后 PNG/JPEG/HEVC 的 embed 分支从同一 CostMap/槽位池返回容量，`stego/io.rs`
  的兜底 probe 只在 `EmbedOutput.capacity == None`（HEIF 缩略图桥）时触发，无需再做解码复用。
- 证据：计数探针显示 `embed`/`capacity`/`extract` 对同一 PNG 各只调用 `decode_png` 1 次；
  4.2 MB PNG：0.12/0.20/0.14 s；30 MB/24.4 MP PNG：2.42/3.15/2.12 s（重复解码应约 4.5 s）。
- 改动：仅修正 `rust/src/stego/options.rs` 中“PNG/JPEG 故意返回 None”的过时注释；无运行时代码变更。
