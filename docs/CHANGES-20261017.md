### 2026-10-17 10:31:05 - 修复 MP4 uuid Box 头部规范符合性（解决 MediaInfo 报 Conformance errors 缺陷）
- **MP4 Box 尺寸规范合规化修复** (`python/strhide/adapters/mp4.py`, `python/strhide/core/engine.py`):
  - **问题根因分析**：原先对所有 `box_uuid` 均强制采用 64 位大尺寸模式（`size = 1` + 8字节 `largesize`），由于在负载 $<4\text{GB}$ 时使用 64 位 Box 违反了 ISO/IEC 14496-12 规范，导致 MediaInfo 等解析器在读取 32 位标准头部时发生 8 字节位移错位，将 UUID 后半段字节误判为巨大尺寸并抛出 `Element size is more than maximal permitted size (actual 11111325229673410384, expected 418)` 等 2 项 Conformance errors。
  - **动态适配合规格式**：
    - 当总块尺寸 $< 4\text{GB}$ 时，严格使用标准 32 位 Box 头部（24 字节：4B 尺寸 + 4B 'uuid' + 16B 中性 UUID）。
    - 当总块尺寸 $\ge 4\text{GB}$ 时，自动升级为 64 位 Large Box 头部（32 字节：4B size=1 + 4B 'uuid' + 8B largesize + 16B UUID）。
    - `locate` 智能双向兼容检测 24 字节标准头部与 32 字节 64 位头部。
  - **实测 MediaInfo 审计验证**：
    - 重新测试 `file-00_box_uuid.mp4`、`file-01_box_uuid.mp4`、`file-04_box_uuid.mp4`，经 `mediainfo` 深度审计，**Conformance errors 由 2 项彻底降为 0 项（100% 完美合规）**。
