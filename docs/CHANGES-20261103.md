### 2026-11-03 14:55:25 - 修复信封版本篡改测试在异或掩码碰撞下的非确定性（Flaky Test）

- **背景与根因**：
  在结构域 UBE 信封中，无密码（默认模式）信封头部字段（偏移 8..12）会被派生密钥进行异或掩码（`disk[8] = version ^ mask[0]`，当前 `version = 0x02`）。测试 `verify_detects_unsupported_envelope_version`（[`rust/tests/test_regression/p2_protocol.rs`](file:///c:/Home/Projects/strhide/rust/tests/test_regression/p2_protocol.rs)）及 CLI 测试 `verify_exit_code_one_when_envelope_header_invalid`（[`rust/tests/test_cli/p2.rs`](file:///c:/Home/Projects/strhide/rust/tests/test_cli/p2.rs)）原本通过直接向偏移 8 写入固定字节 `0x09` 模拟版本篡改。由于随机 salt 生成的 `mask[0]` 具有 $1/256 \approx 0.39\%$ 的概率恰为 `0x0B`，此时磁盘原始字节已为 `0x02 ^ 0x0B = 0x09`，写入操作沦为空操作（No-Op），导致完好载体通过校验并触发断言 panic。
- **修复方案与实现**：

  2. 彻底保证在全量 256 种 `mask[0]` 取值下篡改绝不为空操作，且无论走第 2 级默认解掩码还是第 3 级裸头回退，反解版本均严格不等于 `CURRENT_VERSION (0x02)`；
  3. 清理 `rust/tests/test_cli/p2.rs` 中未使用的死代码 `patch_header_field`。
- **系统性实证验证**：
  1. **1000 次压力回归**：针对修改后的测试运行 1000 次连续测试，实现 0 次失败（0.00% 故障率，修复前为 5 次/1000 次）；

### 2026-11-03 09:42:03 - 修复 HEIF Thumbnail Bridge 在大体量伪随机载荷下误判 JPEG 的隐患

- **背景与现象**：
  在运行 `heavy_dual_domain_coexistence_matrix` 多线程测试时，偶现 `img_heic_0005.HEIC [Content -> Structure] (Case #35)` 在使用错误密码做隔离性断言提取时报错：`Err(CorruptedData("Corrupt JPEG coefficient stream: truncated JPEG data"))`，未能如预期返回 `NoHiddenData`。
- **根本原因排查与实证**：
  1. `img_heic_0005.HEIC` 为纯 Scheme C (HEVC CABAC) 隐写载体，未包含有效的 JPEG 缩略图；在先注入内容域、后以结构域（`item_hidden` 策略）注入 1 MiB 高熵伪随机大载荷后，HEIF 容器体积增大；
  2. Scheme C 在使用错误密码尝试提取时，由于 superblock magic 校验不匹配，正常返回 `NoHiddenData`；
  3. 随后调度回退至 `thumb_bridge::extract_heif_bridge`。在 [rust/src/stego/heif/thumb_bridge.rs](file:///c:/Home/Projects/strhide/rust/src/stego/heif/thumb_bridge.rs) 中，`fallback_scan_jpeg` 与 `parse_exif_embedded_jpeg` 仅以简单的 `FF D8 FF [marker] ... FF D9`（长度 $\ge 4096$）进行无校验启发式扫描；
  4. 经数学概率与仿真验证，1 MiB 伪随机数据中天然存在约 0.51% 概率随机出现合法 SOI+Marker+EOI 的字节序列；多场景并发下触发假阳性，将随机切片识别为 `ContainerJpegFallback` 并送入 `dct_io` 解析，抛出系数流截断损坏异常。
- **架构与实现修复**：
  在 `fallback_scan_jpeg` 及 `parse_exif_embedded_jpeg` 的启发式扫描逻辑中增加 `dct_io::inspect` 规范性前置校验。仅当切片经轻量 DCT 标头检验通过（确认具备完整合规的 SOF/DQT/DHT/SOS 结构）时才采纳为有效桥接目标，彻底杜绝高熵随机数据导致的假阳性。
- **验证结果**：
