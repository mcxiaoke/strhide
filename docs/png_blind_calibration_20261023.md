## 0. 结论

1. **`0.05` 这个阈值在 PNG 上不可用**：107 个干净载体里，RS 21%、SPA 25%、WS 26% 越界（分层采样后升到 27%/30%/33%）。它不是"轻微误报"，而是把四分之一的正常图片判成"可疑"。
2. **分层采样（B2）必须做，但它让数值整体上移**：原来只看顶部 512 行（`wallhaven` 只覆盖顶部 6.7%，竖图顶部往往是天空），改看顶/中/底三段后，同一阈值下越界数从 23/27/28 升到 29/32/35。这不是回归——是原来的采样低估了纹理。
3. **这三个估计器对"LSB 替换"依然有效**：同一批载体把 LSB 全部替换后，中位数 ws 1.000 / rs 0.958 / spa 0.999。因此阈值不是"关掉检测器"，而是把它们调到**它真正建模的那类修改**上：`0.70` 时 107 个干净载体只有 1 个越界（ws、spa 各 1，rs 0），LSB 替换样本仍有 100%/75%/100% 被检出（ws/rs/spa）。
4. **对本项目的三元 `±1` 匹配，这三者基本无响应**：64 B 与 4 KiB 载荷下检测值与载体**逐位相同**；满载（RGB，约 0.9 bpp）时数值反而**下降**（6/6 载体）。这是替换模型检测器的固有盲区，已被本次实测确认，不再是猜测。
5. **独立套件（Aletheia SRNet/EffNet）不能直接当判据**：干净载体上 EffNet-HILL 给 0.48~0.9975（同一批 6 张），SRNet-HILL 给 0.31~0.72。绝对分数不可用；配对比较才有意义——满载时 SRNet-HILL 只在 `0003.png` 上明显上升（0.387→0.731）。
6. **剩余 1 个误报不是我们的 bug**：`0006.png` 在 ws/spa 上饱和到 0.758，独立套件也把它判成 `HIGH_RISK`（75 分，估计嵌入率 35.9%）。属于该图自身的统计异常（平均 99、标准差 69 的普通照片，但估计器在其上发散）。

## 2. B2：分层采样

**改动**（`rust/src/analysis.rs`）：

- 新增 `spatial_slabs()`：按 stride 取顶 / 中 / 底三段**连续行**，每段最多 512 行、4 MB；总行数不足三段时整图分析（小图行为与旧版一致）。
- `track_spatial_domain` 对每个 slab 分别跑 WS/RS/SPA，**按段求平均**（不是取最大：载荷铺满整图，取最大会让一条异常带主导结论）；chi2 改为**汇总直方图**后一次计算，与单趟全图统计等价。
- 之所以不做"把行拼成一个 buffer"：三个检测器都假设垂直相邻（3×3 窗口 / 上下采样对），拼接会凭空造出从未存在的邻居对；分段各自统计是精确的。

**效果**（107 个干净载体，阈值仍为 0.05）：

| 检测器 | 旧（顶部 512 行）p50 / p90 / max / 越界 | 新（三段平均）p50 / p90 / max / 越界 |
| :--- | :--- | :--- |
| WS | 0.017 / 0.202 / 0.933 / 28 | 0.022 / 0.235 / 0.758 / **35** |
| RS | 0.012 / 0.115 / 0.621 / 23 | 0.021 / 0.193 / 0.614 / **29** |
| SPA | 0.019 / 0.156 / 0.784 / 27 | 0.023 / 0.225 / 0.758 / **32** |

单张 1920×1280 的扫描耗时基本不变（0.354 s → 0.354 s；PNG 解码与 deflate 占大头，统计部分不是瓶颈）。

## 3. B3：阈值标定

### 3.1 干净载体 vs LSB 替换载体

| 检测器 | 干净载体 p50 / p90 | LSB 替换 p10 / p50 / p90 |
| :--- | :--- | :--- |
| WS | 0.022 / 0.235 | 0.997 / **1.000** / 1.000 |
| RS | 0.021 / 0.193 | 0.000 / **0.958** / 1.000 |
| SPA | 0.023 / 0.225 | 0.964 / **0.999** / 1.000 |

阈值扫描（FP = 107 个干净载体越界数，TP = 80 个替换样本检出率）：

| 阈值 | WS FP / TP | RS FP / TP | SPA FP / TP |
| ---: | :--- | :--- | :--- |
| 0.50 | 3/107 / 100% | 1/107 / 75% | 1/107 / 100% |
| 0.65 | 1/107 / 100% | 0/107 / 75% | 1/107 / 100% |
| **0.70** | **1/107 / 100%** | **0/107 / 75%** | **1/107 / 100%** |
| 0.80 | 0/107 / 100% | 0/107 / 75% | 0/107 / 100% |

选 `0.70`：仍低于两个饱和样本（0.758），保留一点裕度；再往上 FP 不再下降（饱和样本就是那一个），只是把裕度浪费掉。RS 的 75% 上限来自替换样本里 20 张估计器失效（过曝/极平滑），与阈值无关。

**改动**：`SPATIAL_RATE_THRESHOLD = 0.05 → 0.70`（`analysis.rs`），三个检测器共用；检测器报告里的 `threshold` 字段随常量输出，不再硬编码 "0.050"。

### 3.2 干净载体上的最终分布（107 张）

```
risk 0 / clean          105
risk 2 / clean            1   (只有 ws 越界，Info +2)
risk 27 / low             1   (0006.png: ws 0.758 + spa 0.758)
```

`0006.png` 用独立套件复核也是 `HIGH_RISK`（75 分，估计嵌入率 35.9%），不是本项目独有的误报。

### 3.3 对本项目 `±1` 匹配的响应（6 个载体配对）

| 载体 | 载荷 | WS | RS | SPA |
| :--- | :--- | ---: | ---: | ---: |
| 0001 | 载体 / 64 B / 4 KiB / 满载 | 0.002 / 0.002 / 0.002 / 0.000 | 0.087 / 0.087 / 0.087 / 0.038 | 0.085 / 0.085 / 0.085 / 0.039 |
| 0003 | 同上 | 0.005 / 0.005 / 0.005 / 0.000 | 0.008 / 0.008 / 0.007 / 0.000 | 0.007 / 0.007 / 0.006 / 0.000 |
| 0006 | 同上 | 0.758 / 0.758 / 0.758 / 0.736 | 0.614 / 0.614 / 0.614 / 0.565 | 0.758 / 0.758 / 0.758 / 0.704 |

- 64 B 与 4 KiB：三档检测值**与载体完全相同**（1000 个槽位 / 240 万像素，统计上不可见）。
- 满载（RGB，约 0.9 bpp，约 50% 的 LSB 被 ±1 改写）：6/6 载体上 WS/RS/SPA **全部下降**。原因是三元匹配把差值直方图抹平的程度与替换不同，替换模型估计器把"更多修改"读成"更少嵌入"。

结论：这三者可以检出**替换类**工具（F5/steghide/LSB 顺序替换等），对**匹配类/自适应**嵌入无判别力；扫描器的 PNG 结论不应依赖它们。这一点已写进 `analysis.rs` 的常量文档与 `batch_stego` 的说明。

## 4. 独立套件交叉核对（`scripts/stego_eval`）

Aletheia 系模型 + 四层经典统计，对同一批 6 载体 × 4 变体：

| 文件 | 变体 | 综合分 | EffNet-HILL | SRNet-HILL | SRNet-SUNIW |
| :--- | :--- | ---: | ---: | ---: | ---: |
| 0001 | 载体 / 64 B / 4 KiB / 满载 | 21.9 / 21.9 / 21.9 / 23.1 | 0.593 / 0.593 / 0.593 / 0.641 | 0.335 / 0.338 / 0.342 / 0.467 | 0.447 / 0.447 / 0.448 / 0.383 |
| 0003 | 同上 | 22.9 / 22.9 / 22.9 / **55.0** | 0.998 / 0.998 / 0.998 / 0.995 | 0.387 / 0.399 / 0.327 / **0.731** | 0.453 / 0.459 / 0.371 / 0.719 |
| 0004 | 同上 | 23.8 / 23.8 / 23.8 / **55.0** | 0.993 / 0.993 / 0.992 / 0.988 | 0.715 / 0.715 / 0.719 / 0.730 | 0.678 / 0.676 / 0.678 / 0.731 |
| 0006 | 同上 | 75.0 全程 | 0.586~0.605 | 0.401 / 0.401 / 0.406 / 0.328 | 0.576 / 0.576 / 0.574 / 0.361 |

- **绝对分数不可用作判据**：干净载体上 EffNet-HILL 从 0.48 到 0.9975（6 张），SRNet-HILL 0.31 到 0.72。跨语料偏差比嵌入信号大一个数量级。
- **配对比较有信息**：满载时 `0003` 的 SRNet-HILL 从 0.387 升到 0.731；`0003`/`0004` 的经典层综合分从 ~23 升到 55（SUSPICIOUS）。与 §3.3 里"我们的估计器在满载时反而下降"并不矛盾——两个套件看的是不同统计量。
- 结论与 §3 一致：**低/中载荷不可见；只有接近满容量、且载体本身纹理足够时才有部分可检性**（2/6）。

> 说明：`stegeo_eval` 的 README 仍写着 `temp/stego_eval` 路径，实际在 `scripts/stego_eval`；本次只用其 API/CLI，未改动它。

## 6. 验收

- 干净载体（107 个）：105 个 `0/clean`、1 个 `2/clean`、1 个 `27/low`，**没有 suspicious / likely-hidden**；改造前同一集合有 23~35 个越界检测（21%~33%）。
- LSB 替换样本（80 个）：`risk >= 50` 64/80（80%），检出率 ws/rs/spa = 100%/75%/100%。
- `cargo test` 全绿、`cargo fmt --check` 通过、`cargo clippy --all-targets -D warnings` 无警告。
- `batch_stego` 22/22；满载自检 3~4/18 命中，其中载荷驱动 1~2 个。
- `batch_corpus` 240/240（本轮改动不触及容器层，复跑仅作回归确认）。

## 7. 局限与后续

1. **语料只有 107 个载体**，且 100 个是"相机 JPEG → PNG"的转换件；真实 PNG（截图、渲染图、RAW 导出）样本偏少。阈值应随语料扩大复核，但方向（`0.70` 量级）不会回到 `0.05`。
2. **单图方差大**：`0006.png` 这类图像会让估计器饱和到 0.75。是否要在估计器发散时（例如 ws 与 spa 同时 >0.7 但 rs 很低）标注"估计器不可靠"，留待有更多样本再定。
3. **缺一个匹配类检测器**：要把"我们的嵌入是否可见"变成可测量的结论，需要一个建模 LSB matching 的统计量（残差/邻域直方图类）或有标定的 CNN。现有 NN 模型必须先在目标语料上重新标定阈值（本次实测其干净图分数跨度 0.48~1.00）。
4. CLI 仍未在容量输出里标注"载荷槽位含 RGB 三通道"，同 P3 遗留项。
