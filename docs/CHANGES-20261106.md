## 2026-11-06 23:46:30 — 修复 MiPOD/J-MiPOD 的跨平台字节漂移（代价标定量化）

- **问题（跨平台读出失败）**：`mipod` 写出的 PNG 在 Windows 上嵌入、Linux 上提取会返回 `NoHiddenData`，与错密码不可区分。代价既喂给候选排序也喂给 trellis，末位差就把载荷挪到别的像素上。
- **实测（Ubuntu 22.04 / x86_64 实机 vs 本机 Windows）**：
  - 28 例真实语料 `baseline_hash.py --check`：**28/28 一致**（hill/suniward/mipod、uerd/juniward/jmipod、HEVC、FLAC、WAV 全覆盖）；
  - 合成图矩阵（4 图 × 3 算法，800×800，32 KiB 载荷，固定 `--seed`）：**11/12 一致**，唯一例外是 `mipod` + 纯渐变图（Windows `62f4bc8d…` vs Linux `e852749b…`）。
- **逐阶段定位**：加临时探针比较 `σ²` / `I_n` / `box_smooth` / `cost` 的位模式摘要——前三段两个平台**逐位相同**（`cos` 不是问题），只有 `fisher_to_costs` 的输出不同，幅度 ≤ 255 ulp（相对 `2^-44`）。根因是 Newton 迭代按 `1e-14` 相对残差提前收敛，两侧的切线与停止点略有差别。探针已在提交前移除。
- **修复（`stego/cost_calibration.rs`）**：`fisher_to_costs` 返回前把每个代价的低 20 位尾数清零（`quantize_cost`，相对量子 `2^-32`）。比实测离散度粗 4 个数量级，比任何会改变排序的代价差细 6 个数量级。
  - MiPOD 与 J-MiPOD 共用该函数，两个模型同时受益；`hill`/`suniward` 不经过它（它们的代价只用 `+ - * /` 与 `abs`，本来就一致）。
  - 新增单测 `quantise_cost_is_monotone_and_absorbs_ulp_noise`：±200 ulp 必须收敛到同一个值、保持单调、幂等、0/∞ 原样通过。
- **影响面**：量化后合成矩阵 **12/12 一致**；28 例基线**一例未变**（真实语料的代价间隔远大于量子），因此这次修复对既有产物零字节影响，`baseline.json` 只因重建记录了新的二进制元数据。
- **残留风险（已写进文档）**：两个平台的数值若跨过桶边界仍会差一个量子，概率约 `离散度/量子 ≈ 4e-5`/元素，只能靠跨平台 CI 兜底。`testdata/` 有 845 MB，暂时无法进 CI；文档 §附录 A.2 记录了复现步骤与"挑一小组 ≤5 MB 载体入仓"的前置条件。
