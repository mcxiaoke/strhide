- **【输出透明化与数据模型升级】**：
  - `ScanReport` 新增 `detectors: Vec<DetectorMetric>`，完整记录各检测器在目标文件上的定量测量值（如 `rate`、`suspicion`、`imbalance`、`bytes`）、告警阈值及判定状态（`PASS`/`ALERT`）。
