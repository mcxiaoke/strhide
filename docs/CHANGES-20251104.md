## 2026-11-04 15:39:17 — P2-22（PNG R/B 槽位复核：非缺陷，仅补证据）

- **结论**：非缺陷，未改生产代码。`SlotPlan::build` 的候选池确实只按头部通道（RGB 为 G）做 `[8,247]` 预筛；但 `for_each_body_slot` 在真正取用每个 R/B 槽位时按该通道自身值再次过滤 `[8,247]` 与 `class_rule`。因此 R/B 永远不会被写到类别边界外，embed/extract/probe 共用同一 `SlotPlan`，行为对称。
